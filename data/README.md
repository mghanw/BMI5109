# Input data

All input data come from GEO series
[GSE291147](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE291147) (PerturbFate, A375
CRISPRi screen, Dual-omics RNA). The files are used unchanged, with their GEO file names.

## Getting the RNA count matrix

Option 1, GitHub Release: download
`GSE291147_Dual_omics_RNA_gene_count_matrix.RDS` from
[data-v1](https://github.com/mghanw/BMI5109/releases/tag/data-v1) and save it as
`data/raw/GSE291147_Dual_omics_RNA_gene_count_matrix.RDS` (keep the file name).

Option 2, GEO: from the repository root run

```powershell
powershell -ExecutionPolicy Bypass -File scripts\download_data.ps1
```

The script downloads all three files above from the GEO FTP site into `data/raw/` and skips files
that already exist.

Check the checksum against the table above:

```powershell
Get-FileHash -Algorithm SHA256 data\raw\GSE291147_Dual_omics_RNA_gene_count_matrix.RDS
```

```bash
sha256sum data/raw/GSE291147_Dual_omics_RNA_gene_count_matrix.RDS
```

## Other directories

- `data/ref/`: public reference files (GEO SOFT, paper full text, GENCODE v38 GTF, HGNC, program
  supplements, authors' repository files). Only `SOURCES.md` (URLs, access dates, sizes, SHA256) is
  tracked; the files are fetched with `python -I scripts\fetch_refs.py --download`.
- `data/processed/`: converted matrices and Phase 1 outputs. Not tracked; regenerated by the
  pipeline in the top-level README.

The two tracked GEO files contain cell barcodes as published on GEO. No other cell-level data are
committed to this repository.
